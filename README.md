# Lorentrix website

Open index.html directly, or serve this directory with any static web host. The website ships with local photographs, CSS and JavaScript. No package installation is required.

## Deploy on your own host

Extract this ZIP. Upload index.html, both CSS files, both JavaScript files and the assets directory together into the public directory for your domain. Keep the filenames and folder structure. Choose static hosting and leave the build command empty. The host serves index.html as the home page. The site uses bundled images and system fonts and runs in the visitor’s browser.

## Enquiries

The contact form opens a draft addressed to lorentrix.web@gmail.com. The visitor sends it in their email app. For a custom JSON backend, set window.LORENTRIX_ENQUIRY_URL before app.js loads.
